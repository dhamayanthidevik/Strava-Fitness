# Fitbit / Bellabeat case study

1. `pip install -r requirements.txt`
2. `python build_db.py`   (rebuilds fitbit.db from the CSVs; a ready-made fitbit.db is already included)
3. `streamlit run app.py`

Files: build_db.py (cleaning), queries.py (all SQL), app.py (Streamlit dashboard + SQL Analysis page).
